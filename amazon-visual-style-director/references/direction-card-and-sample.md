# 方向卡、完整样张与 Style ID

## 制作三套方向样张

1. 读取已验证的 Image Creative Brief，并只选择一张代表性副图任务。
2. 三套样张必须使用同一产品、同一副图任务、同一销售任务，以及逐字相同的 `exact_copy`；不得借由改写、删减、翻译或拆分文案制造差异。
3. 每套样张都先联合设计画面和文字，再生成无文字视觉底图，最后以获准字体合成精确文案与图形。样张必须是可评审的完整成品，不得只交付情绪板、文字方向卡或底图。
4. 为每套样张完整写明下列字段：
   - 方向名称。
   - 一秒购买感受：用户在一眼内应获得的购买动机。
   - 视觉叙事：场景、动作、焦点、道具与销售任务之间的因果关系。
   - 镜头与光线：视角、景别、产品重心、明暗层次和材质表现。
   - 色板角色：背景色、产品衬托色、文字色、强调色和其对比职责；按实际产品与场景确定。
   - 字体性格：字重、宽度、圆角或几何感、字距、行距及标题/副标题/数字的层级理由。
   - 文字与产品关系：留白形状、文字锚点、产品轮廓避让和视觉动线。
   - 精确文案：原样列出 Brief 中的全部 `exact_copy`，包括数字、单位、标点、大小写和语言。
   - 图标/线条/色块系统：形状语言、粗细、圆角、密度、颜色角色及其服务信息的方式。
   - 反模板规则：说明此产品的形态、材质、使用时刻或购买动机如何决定本方向；禁止直接复用无关产品的构图、装饰或排版。
   - 禁止的视觉结果：列出与产品真实性、销售任务、合规或审美相冲突的表现。
5. 让三套方向在叙事、光线、色彩关系、字体气质和装饰语言上形成可感知差异；差异必须服务同一销售任务，不得改动产品事实或精确文案。

## 方向样张的无文字底图

在 Image Gen 提示词中明确产品位置、焦点、明暗关系、可用留白和装饰空间。Image Gen 只生成视觉底图：不得生成词语、字母、标签、数字、单位、Logo 或乱码。准确文字、数字、单位和图形必须由确定性合成流程渲染。

## 用户选择与跨方向组合

展示三套完整样张后，要求用户：

- 选择一套方向；或
- 明确指定跨方向组合，并逐项说清采用哪套方向的画面叙事、字体、色彩关系或装饰系统。

不得把未说明的元素自行混入。无论选择单一方向还是组合方向，都必须重新整合为一个产品专属、内部无冲突的 Style ID，然后才开始整套图片制作。

## Style ID 结构

为每个选定或组合后的方向建立并锁定以下字段。字段内容必须描述本产品的实际设计决定，不得填入泛化口号。

```text
creative_thesis
visual_narrative
anti_template_rule
palette_roles
lighting_logic
camera_logic
product_scale_rule
negative_space_rule
typography_master
headline_subtitle_number_hierarchy
icon_and_shape_system
allowed_variations
locked_consistency_rules
```

`allowed_variations` 只记录可随各副图销售任务改变的场景、构图或局部承载方式。`locked_consistency_rules` 必须锁定字体性格、色彩关系、装饰语言、产品表现原则和整体视觉气质。后续单图如需偏离锁定项，先回到方向选择并取得用户确认。
