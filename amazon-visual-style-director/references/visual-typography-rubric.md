# 视觉与字体质量量表

在每张副图完成前，按以下四层逐项验收。任一层不通过，即记录失败原因并路由返工；不得以脚本通过代替审美通过。

## 1. Product Truth（产品真实性）

- 核对形状、比例、颜色、材质、结构、接口、配件、数量、使用方式和可支持功能是否与 Brief 的锁定事实一致。
- 拒绝产品失真、虚构配件、错误结构、错误使用方式和不支持的声明。
- 产品真实性不通过时，退回视觉底图设计与生成，不得只遮盖或重排文字。

## 2. Single-Image Visual Quality（单图视觉质量）

- 判断核心卖点能否在一秒内理解，产品是否处于正确焦点，场景、光线、道具和背景是否服务购买动机。
- 判断构图节奏、产品比例、层次和留白是否自然，是否有无意义装饰、廉价感或机械重复感。
- 检查画面是否遵守该图单一销售任务与 Style ID；不通过时修订协同设计规格，必要时重做视觉底图。

## 3. Typography-to-Image Harmony（字体与画面协同）

- 判断字体性格是否呼应产品形态、材料、场景和购买情绪。
- 判断文字色彩与产品色、背景色、亮度及强调角色是否协调且可读；不得机械套用色值。
- 判断标题、副标题、数字和单位是否沿着画面视觉路径排列，是否避开产品轮廓与关键细节。
- 判断文字是否有自然锚点，例如留白、承载面、光影区或受控图形元素；不得像事后贴上去。
- 判断缩略图尺寸下的层级与可读性，并核对 `exact_copy` 是否逐字准确：文字、数字、单位、标点、大小写、语言和强调词均不得变更。
- 判断图标、线条、色块、阴影与文字是否属于同一设计系统。

## 4. Set Consistency（整套一致性）

- 核对每张图是否继承同一 Style ID 的字体性格、色彩关系、光线逻辑、镜头逻辑和装饰语言。
- 核对不同销售任务是否仍清晰区分，且不存在重复表达、产品外观漂移或品牌气质断裂。
- 判断整套是否像同一品牌、同一设计师在同一视觉合同下完成；发现 Style ID 本身不成立时，回到三方向样张与用户选择阶段。

## 审美决策与执行边界

在生成视觉底图之前，先决定文字区域、留白形状、色彩角色、视觉路径和承载元素，并将这些决定写入画面规格与生成提示词。生成 `visual-plate` 后，再观察实际明暗、主要颜色、焦点、产品边缘、材质和有效留白；在既定 Style ID 内调整文字颜色、字号、位置、承载面板、阴影或装饰线，并重新验收最终合成图。

脚本只忠实执行并校验已经声明的设计：渲染精确文字与图形、检查尺寸和越界、保留交付物。脚本不得自行决定审美、替换字体、修改文案或选择画面方向。
