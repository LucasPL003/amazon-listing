# Amazon.co.jp Image Workflow

Use this reference when converting competitor listing research into a new Japanese Amazon image set.

## Listing Extraction Checklist

Capture the visible facts before interpreting:

- Product title and implied keyword structure
- Brand/store name and any visible series/model naming
- Price, coupons, rating, review count, and obvious bestseller/social proof badges
- Main image, sub images, video covers, variation images, A+ images, comparison charts
- Bullet points, description, A+ copy, spec table, included accessories, warranty/support notes
- Visible review themes, Q&A concerns, and repeated customer language

If page access is incomplete, state exactly what was blocked and continue with available material only after asking the user to complete in-app browser login/region checks where needed.

## Advantage Extraction

Distill advantages from evidence rather than from guesswork:

- Functional advantage: what the product does better or more conveniently
- Material/quality advantage: material, build, durability, safety, finish, texture
- Scenario advantage: where, when, and for whom it is useful
- Bundle/value advantage: quantity, accessories, compatibility, gifting, storage
- Trust advantage: warranty, reviews, certifications, support, clear instructions
- Emotional advantage: cleaner home, easier routine, premium feel, cute design, calm workspace

For each advantage, mark the source: title, bullet, spec, image, A+ section, review, or inference.

## Three Style Recommendations

Recommend three styles that fit the actual product category and audience. Avoid generic styles. Each style must include:

- Style name
- Visual keywords
- Color/background direction
- Main image approach
- Sub image roles that suit the style
- Why it fits this product
- Risk or limitation

Choose one default style. Prefer the style that is easiest to make compliant, clear at thumbnail size, and differentiated from the competitor.

## Image Set Planning

Default size: export every Amazon main/sub image as a 1500 x 1500 px square image unless the user explicitly requests another size.

Default set:

- Main image: product-first, clean, high clarity, no competitor brand elements
- Sub image 1: core benefit at a glance
- Sub image 2: feature/detail close-up
- Sub image 3: usage scenario or lifestyle context
- Sub image 4: size/spec/accessory explanation
- Sub image 5: comparison, before/after, or problem-solution
- Sub image 6: trust, package contents, care instructions, or gifting angle
- Sub image 7: optional seasonal, variation, compatibility, or review-driven concern

Use Japanese-language callouts only when the user wants text in-image or when the product category benefits from quick comprehension. Keep text short and avoid claims that are not supported by the user's product facts.

## Prompt Construction

For each generated image prompt, include:

- Product identity and user-provided visual assets to preserve
- Image role and target buyer takeaway
- Composition, camera angle, background, props, lighting, and color direction
- Text/callout content if needed
- Explicit exclusions: no competitor brand/logo/packaging/watermark/copied layout
- Output requirements: 1500 x 1500 px square canvas, high resolution, e-commerce product photography, clean readable text

When using generated lifestyle scenes, keep the product physically plausible and avoid misleading scale, use, or included accessories.
