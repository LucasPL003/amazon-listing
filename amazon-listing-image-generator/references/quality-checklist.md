# 图片质量检查

每张图单独检查并记录通过或失败，不得用整套平均质量掩盖单图问题。

## 产品真实与事实

- [ ] 产品形状、比例、颜色、材质、结构、接口、配件、数量和可见功能与原始产品图片一致。
- [ ] 没有虚构参数、尺寸、功能、场景、认证或效果主张。
- [ ] 没有迁移风格参考中的产品、品牌、Logo、文案、认证或其他资产。
- [ ] 未知细节保持未知，没有为了美观而补全或重塑。

## 整套一致性与销售表达

- [ ] 所有图片使用同一 Style Pack ID，并共享一致的配色关系、背景处理、光影语言、构图节奏和排版感觉。
- [ ] 每张图片只有一个独特的核心销售任务，和其他图片没有无意义重复。
- [ ] 产品与核心信息一秒内可识别，场景、道具和光影服务真实使用情境与购买吸引力。
- [ ] 除结构、尺寸、步骤、分层材料和合规对比等明确的信息图任务外，副图至少 60% 为真实使用场景图，数量按适用副图向上取整。
- [ ] 每张场景图的背景适配均可追溯到已确认的产品用途、目标人群和唯一销售任务；人物、动作、道具与环境没有暗示未经确认的功能、参数、效果或安全主张。
- [ ] 画面不是机械套模板，且没有与产品无关的装饰。

## 文案与合规

- [ ] 主图无可见文字，并满足目标 Amazon 站点的主图要求。
- [ ] 副图文案与已批准文本逐字一致，无乱码、错字、缺字、错误数字或单位。
- [ ] 所有可见声明都有上游事实支持，语言与目标站点一致。
- [ ] 图片满足目标站点的图片与内容合规要求。

## 返工上限

失败时只重新生成失败图片，不影响已通过图片。每张失败图片自动返工最多 2 次；第二次后仍失败则停止自动重试，保留当前最佳结果，列出未通过项并等待用户决定。
