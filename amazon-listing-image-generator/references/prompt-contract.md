# 内部提示词契约

每张图片在生成前必须建立一份内部记录。默认不向用户展示该记录中的完整提示词、负面约束、来源映射或模型设置。

## 必需字段

- 来源 `附图策划` 条目
- 唯一核心销售任务与图片角色
- 已确认事实和有上游证据支持的主张
- 未知项、禁止声明与产品真实性锁定项
- 所选 Style Pack ID
- 当前角色选中的本地参考图片路径
- 主体位置、镜头感、构图、裁切、层级和留白
- 场景、道具、背景、光线、阴影、材质和色彩关系
- 场景依据、目标人群、背景适配理由，以及该背景如何服务唯一销售任务
- 已批准的准确文案、语言、拼写、标点、数字、单位、位置和排版感觉
- 负面约束
- 可直接提交给 Image Gen 的完整提示词

## 参考职责分离

**产品身份参考**：只使用用户的原始产品图片确定形状、比例、颜色、材质、结构、接口、配件、数量和可见功能。未知细节保持未知，不得用美观理由补全或重塑产品。

**风格参考**：只使用 Style Pack 参考图片确定视觉氛围、构图节奏、光影、色彩关系、背景处理和排版感觉。角色专属参考优先；缺失时使用 `generic`。

完整提示词必须明确标记这两类输入的不同职责，不能把所有图片路径无差别交给模型。

## 禁止迁移

不得从风格参考迁移或复制产品、品牌、Logo、文案、认证、装饰标记、包装、参数、功能、使用主张或其他可识别资产。风格参考不能成为任何产品事实来源。

## 生成约束

- 主图：纯净合规背景、无可见文字，产品身份完全来自产品身份参考。
- 副图：画面与已批准文案在同一次请求中生成；文案必须逐字一致。
- 每张图只有一个主要销售信息，所有场景和道具服务于该信息。
- 除结构、尺寸、步骤、分层材料和合规对比等明确的信息图任务外，副图至少 60% 使用真实使用场景；场景、人物、道具和背景必须有已确认的产品用途、目标人群与唯一销售任务依据。
- 场景、人物、道具和背景不得引入或暗示未经确认的功能、参数、效果或安全主张。
