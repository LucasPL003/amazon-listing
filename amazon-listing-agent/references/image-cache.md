# Shared Image Analysis Cache

Use this protocol when any skill needs product image analysis generated by `amazon-listing-agent`.

## Cache Location

Default:

```text
%USERPROFILE%\.codex\shared\image-analysis-cache.json
```

Override:

```powershell
$env:LISTING_IMAGE_CACHE_PATH="C:\tmp\image-analysis-cache.json"
```

## CLI

Use the script from the skill folder:

```powershell
python scripts/image_cache.py path
python scripts/image_cache.py list
python scripts/image_cache.py latest --product-id "sku-001"
python scripts/image_cache.py read --cache-key "<cache-key>"
python scripts/image_cache.py write --product-id "sku-001" --image "C:\path\main.png" --summary "Blue silicone spatula..." --facts-json "{\"color\":\"blue\",\"material\":\"silicone\"}"
```

## Entry Schema

```json
{
  "cache_key": "string",
  "product_id": "string",
  "image_fingerprints": ["sha256"],
  "image_paths": ["string"],
  "summary": "one reusable image analysis snapshot",
  "facts": {
    "color": "blue",
    "material": "silicone",
    "shape": "spatula",
    "functions": ["heat resistant"]
  },
  "source_skill": "amazon-listing-agent",
  "created_at": "ISO-8601",
  "updated_at": "ISO-8601"
}
```

## Reuse Rules

- Prefer `latest --product-id` when the product identity is known.
- Prefer `read --cache-key` when a previous response exposed the cache key.
- Treat cached image analysis as authoritative for the current product unless the user provides new images or says the image changed.
- If new images are provided, write a fresh entry after analysis.
- Do not store image bytes in the cache; store fingerprints, paths, summary, and structured facts.
